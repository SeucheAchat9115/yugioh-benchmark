# Yu-Gi-Oh! Benchmark

Replay conversion and reviewed decision benchmarks for agentic Yu-Gi-Oh! play.

This repository is being initialized with a DuelingBook importer and a versioned
JSON replay format. Extracted simulator operations are observations, not certified
legal moves or automatically graded strategic decisions. The target integration
is [yugioh-harness](https://github.com/SeucheAchat9115/yugioh-harness).
